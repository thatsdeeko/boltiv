BOLTIV Education Route Fix v3

Fixed the VTUGATE education pricing integration to match the documented API contract.

Documented endpoint:
POST /api/v1/geteducationtypeprice
Content-Type: application/x-www-form-urlencoded
Authorization: Bearer {YOUR_API_KEY}
Body: service_id={EDUCATION_SERVICE_ID}

The WAEC documentation example confirms service_id=1, so WAEC is configured to use 1 by default.
NECO/JAMB/NABTEB service IDs are read from Render environment variables:
VTU_EDUCATION_NECO_SERVICE_ID
VTU_EDUCATION_JAMB_SERVICE_ID
VTU_EDUCATION_NABTEB_SERVICE_ID

BOLTIV applies the selected quantity after receiving the per-pin price.
The existing revenue calculation was not changed.
