# Boltiv SEO / Indexing setup

- Homepage is indexable with canonical URL and Organization/WebSite schema.
- Public service pages are indexable and included in sitemap.xml.
- Authenticated/private pages remain noindex and are excluded from robots crawling.
- Submit https://boltiv.ng/sitemap.xml in Google Search Console.
- If Search Console asks for verification, add the verification meta tag/file provided by Google.
